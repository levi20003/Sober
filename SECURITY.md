# Biztonsági szabályzat / Security policy

## Sebezhetőség bejelentése
Ha biztonsági hibát találsz, **ne nyiss nyilvános GitHub-issue-t**. Írj a repó tulajdonosának a GitHub privát sebezhetőség-bejelentő felületén: **Security → Report a vulnerability** (GitHub Private Vulnerability Reporting). Kérjük, írd le a hibát, a reprodukálás lépéseit és a lehetséges hatást. Valódi személyes adatot ne küldj.

- Visszajelzés: legkésőbb 7 napon belül.
- Javítás: a súlyosságtól függően; kritikus hibánál a lehető leghamarabb, és kiadás előtt egyeztetünk veled a közzétételről.
- Köszönetet mondunk a jelentésben (ha kéred), pénzbeli jutalmat nem tudunk adni.

## Hatókör
A `levi20003/Sober` repó kódja: a webes (PWA) és az Android-alkalmazás. Részletek: `docs/audit/AUDIT-SCOPE.md`, fenyegetésmodell: `docs/SECURITY-MODEL.md`.

## Report a vulnerability (English)
Please do **not** open a public issue. Use GitHub **Security → Report a vulnerability** (private reporting). We aim to respond within 7 days.

> **[EMBERI TEENDŐ]** A repó beállításaiban engedélyezni kell a „Private vulnerability reporting"-ot (Settings → Code security).
